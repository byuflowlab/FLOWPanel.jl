## Threading decisions (measured-cost order, binding protocol)

1. **dagplan repack — THREADED** (FastMultipole `29fcdcb2`): parallel over
   source leaves `j` under `setup_threads >= 1`. Race-free and bitwise by
   construction: iteration j writes only `Umat[j]` and, within each
   `Lmat[i]`, the column block at j's colofs offset — disjoint across j —
   with pure elementwise converts (no accumulation, no shared scratch).
2. **leaf LU caches (`build_leaf_lu_cache`, `build_leaf_lu_cache_as`) —
   THREADED** (same commit): per-block `lu!` via `@spawn`/fetch;
   independent blocks, deterministic per block → bitwise.
3. **NOT threaded, by measurement** (recorded per protocol): `sort_by_source`
   (lists total 0.003/0.016 s), trees (0.04/0.10 s), dagplan alloc
   (0.28/0.21 s), bookkeep — all noise-level after (1)+(2).
4. Accepted-serial: critical-path priority pass (unchanged).

No new knob: everything gates on the existing `threaded_setup`/
`setup_threads` opt-in; default path is byte-identical serial code.
