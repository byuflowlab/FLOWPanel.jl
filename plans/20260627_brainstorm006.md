### What has been done

**Item 006 Phase 3 (RPM=5400, NT=18)** established a rlxf stability ladder for corrected-Pedrizzetti VPM relaxation. All runs: depth=4R, withdraw=12 rev, settle=30 rev, BERNOULLI_ONLY=true.

| rlxf | stable? | CT (final-10-rev) | ptp | note |
|------|---------|-------------------|-----|------|
| 0.01 | **NO** | — | — | blows up rev ≈13.7 (CFy→O(1) → OOM) |
| 0.025 | **NO** | — | — | blows up rev ≈13.7 → OOM |
| **0.03** | YES | **0.0665** | 0.0027 | stability floor; just below 0.068 band |
| 0.04 | YES | 0.0660 | 0.0087 | stable |
| 0.05 | YES | 0.0631 | 0.0020 | steady limit cycle |
| 0.1 | YES | 0.0630 | — | stable |

**Blow-up signature**: A lateral-force `CFy` instability grows from ~1e-3 to O(1) at rev ≈13.7 (the moment the freestream finishes withdrawing into hover), then NaN/OOM. This onset rev is **rlxf-independent**; RPM=6000 (smaller dt) was stable at the same transition even at rlxf=0 → **the gate is temporal (dt/CFL), not rlxf**.

**Reference**: DJI9443 hover CT band **0.068–0.072** at **RPM=5400**.  
**Hypothesis**: NT=36 (dt = 60/5400/36 ≈ 0.000309 s vs NT=18 dt ≈ 0.000617 s) should stabilize at lower rlxf, potentially allowing in-band CT.

### What this plan does

Tests NT=36 then NT=72 at two relaxation levels (rlxf=0.3 and 0.6) to:
1. Confirm stability at these NT values
2. Measure CT and its temporal convergence (NT=36 vs NT=72)
3. Determine if CT increases toward the 0.068–0.072 band with NT refinement

If unexpected instability is found, two interventions are available (see Waves C and D).

## Sunday break function

Define this shell function before running any wave. Call it before each wave launch.

```bash
check_sunday_break() {
    local SUNDAY_START SUNDAY_END NOW WAIT
    # GNU date (Linux):
    SUNDAY_START=$(date -d "2026-06-28 00:00:00" +%s 2>/dev/null) || \
        SUNDAY_START=$(date -j -f "%Y-%m-%d %H:%M:%S" "2026-06-28 00:00:00" +%s)
    SUNDAY_END=$(date -d "2026-06-29 00:00:00" +%s 2>/dev/null) || \
        SUNDAY_END=$(date -j -f "%Y-%m-%d %H:%M:%S" "2026-06-29 00:00:00" +%s)
    NOW=$(date +%s)
    if [ "$NOW" -ge "$SUNDAY_START" ] && [ "$NOW" -lt "$SUNDAY_END" ]; then
        WAIT=$((SUNDAY_END - NOW))
        echo "[$(date)] Sunday break in effect. Sleeping ${WAIT}s until Mon 2026-06-29 00:00."
        sleep "$WAIT"
    fi
}
```
